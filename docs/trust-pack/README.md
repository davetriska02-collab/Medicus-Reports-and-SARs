# Trust Pack

The compliance evidence NHS buyers and IG leads ask for, drafted against the
product's actual controls:

| Document | Purpose |
|---|---|
| [`DPIA.md`](DPIA.md) | Data Protection Impact Assessment — pre-filled template; practice completes the **[PRACTICE]** sections and signs |
| [`CLINICAL_SAFETY_CASE.md`](CLINICAL_SAFETY_CASE.md) | DCB0129 clinical safety case with the hazard log (H1–H8), residual risk scores and test evidence |
| [`DSPT_MAPPING.md`](DSPT_MAPPING.md) | Mapping of product controls to the ten DSPT data security standards |
| [`../../SECURITY.md`](../../SECURITY.md) | Security architecture: data flows, storage, auth, transport, redaction integrity, audit |
| [`../TOOLSET_OVERVIEW.md`](../TOOLSET_OVERVIEW.md) | Full capability overview — what the product does, organised by function |

These are living documents — review them at each release alongside the
version history in the README. Nothing here replaces the practice's own
policies; organisational items are explicitly marked.
